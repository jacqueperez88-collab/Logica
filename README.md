# Lógica
# Matemática General — Sitio de Cátedra 📐

Material interactivo para la materia **Matemática General**
(Universidad Nacional del Comahue · 2.º cuatrimestre 2026).
Basado en los apuntes del **Prof. Gustavo Vazquez**.

## Páginas para los alumnos

| Tema | Link |
|------|------|
| Teoría de Conjuntos | [conjuntos](https://TU-USUARIO.github.io/conjuntos/) |
| Lógica Proposicional | [lógica](https://TU-USUARIO.github.io/conjuntos/logica.html) |

## Contenido

### Conjuntos
- Conceptos básicos, pertenencia e inclusión
- Laboratorio interactivo de operaciones (∩, ∪, −, △, complemento)
- Conjunto de partes, cardinal y ejercicios resueltos

### Lógica
- Proposiciones y conectivos (∧, ∨, ∼, ⟹, ⟺)
- Laboratorio de tablas de verdad interactivo
- Tautología, contradicción y contingencia
- Ejercicios de las Fichas Prácticas N.º 1 y 2 con autocorrección

## Cómo actualizar el sitio

1. Editar los archivos `index.html` y `logica.html` localmente.
2. Subirlos con **Add file → Upload files**.
3. GitHub Pages actualiza la página automáticamente en ~2 minutos.
